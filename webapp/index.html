数据同步 备份 / 导入 / 导出
把档案、投递记录、设置做成可携带的备份，或导出成 Excel/Word/PDF 用于投递与归档。所有操作仅读写本地，不联网、不动你的数据。

整包备份 JSON

导出全部档案（含三版本）+ 投递记录 + 设置 + 校招情报缓存的完整快照，用于迁移或回滚。

投递记录导出 所见即所得

按当前筛选 / 搜索结果导出，Excel(CSV) / Word / PDF 三种格式。

档案确认导出

导出 19 类档案字段（不含校招情报），Word / PDF 两种格式。

WebDAV 云同步 可选

配置 WebDAV 后，可把本地档案/投递记录一键同步到私有云盘（如坚果云），换设备也能恢复。

存储与隐私

查看本浏览器「本地存储」中保存了哪些数据；一键清除全部本地数据（不可恢复）。

说明：整包备份 / 导入恢复 / WebDAV 云同步均为真实可用功能；WebDAV 需先在「⚙ 配置」填入坚果云等私有云盘的地址与「第三方应用密码」。查看本地存储与「调试」页同款。
