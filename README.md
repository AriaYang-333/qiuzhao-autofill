## 它解决什么问题

秋招高峰期，每个求职者要在 **8+ 家招聘官网**（腾讯、字节、美团、京东、字节、大疆、安踏、蔚来、小鹏…）重复填写**结构几乎一样**的简历表单：姓名、手机、教育、实习、项目、获奖、语言……**单家 20–40 分钟，10 家就是 3–7 小时**纯机械劳动。

**本项目把这件事变成 1–5 分钟：**
- ① 一次录入 19 类档案；
- ② 拆成 N 个简历版本（运营版/产品版/技术版/秋招版…）；
- ③ 打开招聘页 → 点右下角 ✦ 小球 → 选版本 → **⚡ 一键投递** → 标黄漏项 → 人工核对 → 手动提交。

## 5 分钟上手

### 1. 安装插件
1. 下载本仓库 [Releases](https://github.com/AriaYang-333/qiuzhao-autofill/releases) 最新版 zip；
2. 解压到固定文件夹（别删别移动）；
3. 打开 `chrome://extensions` → 开启**开发者模式** → **加载已解压的扩展程序** → 选解压目录；
4. 点拼图图标，把「秋招网申助手」**固定到工具栏**。

### 2. 录入简历
打开网页版资料库（本地服务或部署站）：
- 填 19 类档案（基本信息 / 教育 / 实习 / 项目 / 获奖 / 语言 / 证书 / 作品集 / 竞赛…）；
- 拆成多个简历版本（不同岗位用不同版本）；
- 点「**🔄 立即同步到插件**」→ 插件 storage 出现多份简历。

### 3. 招聘页一键填充
1. 打开招聘官网 → 登录 → 进入「我的简历 / 编辑简历」；
2. 右下角出现 **✦ 小球** → 点击展开助手卡片；
3. 顶部「选择简历版本」下拉选版本（运营版/产品版…）；
4. 点「**⚡ 一键投递**」→ 自动按档案逐字段填充（含下拉/日期/级联）；
5. 未填字段自动**标黄** → 人工核对 → 手动点「保存 / 提交」（插件不碰提交按钮）。

## 核心特性

| 特性 | 说明 |
|---|---|
| 🎯 **真实大厂深度适配** | 不是通用模板，而是对每家官网的表单结构、下拉组件、级联逻辑**逐一适配**（覆盖 8 家真实招聘站） |
| 🔄 **多版本切换** | 一份资料库拆成 N 个简历版本（运营/产品/技术…），下拉切换即可换档 |
| 🛡 **只填不提交** | 工具严格不碰提交按钮、不处理验证码、不绕过登录，**投递永远是你手动确认** |
| 🚫 **无数据不填** | 凡档案里没有的字段（亲友入职、是否调剂等），一律不填，不编造 |
| 🟡 **未填标黄 + 查漏面板** | 填完自动标黄漏项 + 右侧汇总，一眼看清哪里没填 |
| 🧠 **事件桥同步通道** | 网页↔插件通过 DOM 事件桥（__RFA_SETSTORAGE__）打通，绕开普通网页无 chrome.runtime 的限制 |
| 📅 **校招情报每日更新** | 每天自动汇总的招聘信息（今日/昨日/全部），按公司/岗位/城市/是否免笔试筛选 |
| 📋 **投递记录追踪** | 记录投了哪家、什么状态，可导出 Excel / Word / PDF 复盘 |
| 🔁 **3 份简历上限** | 插件内最多 3 份简历版本（足够 3 个不同方向岗位） |
| 🪟 **可拖动悬浮球** | 右下角 ✦ 小球可自由拖动，刷新页面位置保留 |

## 体系与适配器架构

```
一份 Word 简历
    ↓  解析
19 类标准档案 Schema（basic / education / internships / projects / awards / languages / ...）
    ↓  拆版本
N 个简历版本（运营版 / 产品版 / 技术版 / ...）
    ↓  按版本同步到插件
    │
    ├─→ 飞书系适配器（蔚来 / 小鹏 / 小米 / 携程）：同一套飞书表单组件
    ├─→ Moka 系适配器（大疆 / 安踏 / 元戎 / 速腾 / 阶跃）：53~54 字段一套通吃
    ├─→ 字节自研适配器
    └─→ 通用 Ant Design 适配器（腾讯 / 京东 / 美团 / 拼多多）
    ↓  一键填充（DOM 事件桥 + content script）
    ↓  标黄查漏 + 人工核对
    ↓  手动提交（插件不碰）
```

## 4 条铁律（写进了产品里）

1. **只填有数据的字段** — 档案里没有的（亲友入职、是否调剂等），一律不填，不编造
2. **弹窗只点「否/取消」** — 遇到「解析/覆盖/同步更新」类弹窗，自动选否，保护已填内容
3. **未填字段标黄** — 填完自动标黄漏项 + 汇总面板，一眼看清哪里没填
4. **只填不提交** — 不碰提交按钮、不处理验证码、不绕过登录；不写"快投"等违规文案

## 隐私与安全

- ✅ **数据只存本地**（`chrome.storage.local`），不连任何远端服务器
- ✅ **不碰验证码、不绕过登录**（SSO 需用户自己登录）
- ✅ **不收集个人敏感信息**（手机/身份证/邮箱等只在用户档案里）
- ✅ **一键清空**：插件有 ④「恢复出厂」按钮，可一键清空所有本地数据（不可恢复）
- ✅ **照片压缩 ≤300KB / 简历 PDF ≤6MB**

## 常见问题

**Q: 装好了但打开招聘页没看到 ✦ 小球？**
A: ① 确认扩展已加载（`chrome://extensions` 看是否启用）② 完全退出 Chrome 重开（content.js 改动后必须整体重启浏览器）③ 刷新招聘页面。

**Q: 填充了但有些字段是空的？**
A: 这是**正常的**——插件严格遵循"无数据不填"原则。如果档案里有数据但没填上，说明是该站点的映射/组件未支持，请开 Issue 报告站点 URL + 截图。

**Q: 会不会被招聘系统检测到？**
A: 不会。本插件**只填不提交**，不碰提交按钮、不处理验证码、不绕过登录。所有操作在你登录后的页面里完成，行为与手动填表无异。

**Q: 数据安全吗？会同步到云端吗？**
A: 数据只存本地（浏览器 `chrome.storage.local`），不连任何远端服务器。卸载扩展 = 数据彻底清空。

**Q: 怎么更新到最新版？**
A: 下载新 Release zip → 在 `chrome://extensions` 页面**点本扩展的 ↻ 重载**即可。数据保留。
