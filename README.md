# 秋招网申助手（Chrome 扩展 + Web 资料库）

一个帮你在各大招聘官网一键填充简历表单的自动化效率工具。规则驱动 + DOM 智能识别，覆盖基本信息 / 教育 / 实习 / 项目 / 校园 / 获奖 / 证书 / 论文 / 竞赛 / 语言 / 求职意向 / AI 技能 / 自定义字段等全套资料。

> 定位说明：本产品本质是「规则驱动 + DOM 智能识别」的自动化（RPA 风格）工具，非大模型生成式 AI；可表述为「用 AI 协作从 0 到 1 打造的智能求职效率产品」。

## 功能

- **一键填充**：打开任意招聘官网，点开插件面板即可把档案自动填入表单（仅填有数据的字段，无数据不填）。
- **只填不提交**：自动填充但不点提交/投递、不碰验证码，安全可控。
- **完整资料库**：基本信息、教育、实习、项目、校园、获奖、证书、论文、竞赛、语言、求职意向、AI 技能、技能、证明人、自我评价、自定义字段，全部支持增 / 删 / 排序。
- **档案导出 / 导入**：面板内一键导出档案 JSON，可备份或迁移。
- **投递记录**：内置 tracker，记录投递公司与状态。
- **Web 版资料库**：`webapp/index.html` 是配套的纯前端资料库（localStorage 持久化），可在浏览器里维护档案并导出 JSON 供扩展使用。

## 安装（开发者模式加载）

1. 下载 `秋招网申助手-v0.8.10.zip` 并解压。
2. Chrome 打开 `chrome://extensions`。
3. 右上角开启「开发者模式」。
4. 点「加载已解压的扩展程序」→ 选择解压后的目录。
5. 在招聘官网点开扩展图标，确认档案后一键填充。

## 目录

```
manifest.json / background.js / content.js   扩展核心
popup.html / popup.css / popup.js            插件面板 UI
tracker.html / debug.html / management.html  辅助页面
districts.json / full_profile_seed.json      地址四级数据 / 示例档案
pdf.min.js / pdf.worker.min.js               简历 PDF 解析
webapp/index.html                            纯前端 Web 资料库
```

## Web 资料库部署（GitHub Pages，可选）

将 `webapp/` 目录推到仓库并开启 Pages（Settings → Pages → 选分支根目录）即可获得公开访问地址。该页面纯前端、数据存于浏览器 localStorage，不上传服务器。

## 隐私

档案仅保存在本地浏览器（Chrome 扩展 storage / 网页 localStorage）。未启用云端同步时不向任何第三方上传简历内容。
